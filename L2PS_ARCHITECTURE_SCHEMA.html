🔐 L2PS Architecture

Layer 2 Privacy Subnets - Privacy-Preserving Transactions with Validator Consensus

📋 System Overview

L2PS (Layer 2 Privacy Subnets) is a privacy-preserving transaction system integrated with DTR (Distributed Transaction Routing). It enables private transactions while maintaining validator consensus participation through a unique separation of concerns.

Core Principle: L2PS participant nodes see encrypted transaction content while validators only receive cryptographic hash summaries, ensuring zero transaction visibility at the consensus layer.

L2PS Participant Nodes

  • Non-validator RPC nodes
  • Store encrypted transactions
  • Can decrypt and process
  • Generate hash summaries
  • Participate in L2PS networks

Validators

  • Consensus layer nodes
  • Receive only hash mappings
  • Zero transaction visibility
  • Maintain consensus integrity
  • Store UID → Hash mappings

DTR (Distributed Transaction Routing)

  • Routes transactions to validators
  • Self-directed transaction pattern
  • Load balancing across validators
  • Automatic retry mechanism
  • Production-mode enforcement

🔐 Privacy Model

L2PS Participant Node

  • Stores encrypted transactions
  • Can decrypt transaction content
  • Processes L2PS transactions
  • Generates hash summaries
  • Full transaction visibility
  • Not part of consensus

Validator Node

  • Receives only hash mappings
  • Cannot decrypt transactions
  • Zero transaction visibility
  • Validates hash updates
  • Participates in consensus
  • Privacy-blind operation
Privacy Guarantee: Validators never have access to L2PS transaction content. They only see cryptographic hashes representing the state of L2PS networks, enabling consensus participation without compromising transaction privacy.

💻 Code Examples

Hash Generation Algorithm

// Deterministic hash generation for L2PS UID const transactions = await L2PSMempool.getByUID(l2psUid, "processed") // Sort hashes for deterministic output const sortedHashes = transactions .map(tx => tx.hash) .sort() // Create consolidated hash: UID + count + all hashes const hashInput = `L2PS_${l2psUid}_ALL:${sortedHashes.length}:${sortedHashes.join(",")}` const consolidatedHash = Hashing.sha256(hashInput)

L2PS Transaction Processing

// Load L2PS network instance const parallelNetworks = ParallelNetworks.getInstance() const l2psInstance = await parallelNetworks.getL2PS(l2psUid) // Decrypt transaction const decryptedTx = await l2psInstance.decryptTx(l2psTx) // Verify signature const verified = await Transaction.confirmTx(decryptedTx, decryptedTx.content.from) // Check for duplicates const exists = await L2PSMempool.existsByOriginalHash(originalHash) // Store encrypted transaction (privacy preserved) await L2PSMempool.addTransaction(l2psUid, l2psTx, originalHash, "processed")
