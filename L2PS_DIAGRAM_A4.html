🔒 Privacy Separation Model

L2PS Participants See:
  • Full transaction content
  • Encrypted storage
  • Can decrypt locally
  • Not in consensus
Validators See:
  • Only hash mappings
  • Zero TX visibility
  • Cannot decrypt
  • Participate in consensus

🔑 Key Principle: Complete data separation ensures validators participate in consensus without accessing transaction content. L2PS nodes handle private transactions while validators maintain integrity through cryptographic hash verification.
