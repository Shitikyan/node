L2PS Nodes (Full Visibility)

  • Decrypt transaction content
  • Process L2PS transactions
  • Store encrypted data
  • Generate hash summaries
  • Not part of consensus

Validators (Privacy-Blind)

  • Cannot decrypt transactions
  • Zero TX content visibility
  • Receive only hash mappings
  • Validate hash updates
  • Participate in consensus
